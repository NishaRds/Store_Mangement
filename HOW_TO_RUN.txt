                    STOCKFLOW - HOW TO RUN & DEPLOYMENT GUIDE
   Inventory, Billing and Sales Management System for Small Kirana/General Stores

PROJECT STRUCTURE:
-----------------
stockflow/
  ├── index.html            - Login, 3-step registration, forgot password (multilingual)
  ├── auth.js               - Auth controller, i18n dictionary (EN, KN, HI), tabs
  ├── auth.css              - Calm green & cream auth page styling
  ├── dashboard.html        - POS, Inventory, Customers/Udhaar, Sales, Staff, Settings
  ├── app.js                - Dashboard controller, SVG weekly sales chart, sync
  ├── style.css             - Responsive calm green/cream theme, dark mode, print styles
  ├── config.js             - Single configuration line for backend API endpoint
  ├── sample_inventory.csv  - Sample dataset of 40 general-store items with expiry dates
  ├── HOW_TO_RUN.txt        - This guide
  ├── .gitignore            - Ignores node_modules, .env, *.db, .jwt-secret
  └── backend/
      ├── package.json      - Dependencies (express, better-sqlite3, bcryptjs, cors)
      ├── server.js         - Express API, HMAC-SHA256 tokens, rate-limiter, transactions
      └── db.js             - SQLite database schema, WAL mode, indexing


1. PREREQUISITES:
----------------
- Node.js (v18 or higher recommended)
- A modern web browser (Chrome, Edge, Firefox, Safari)


2. HOW TO RUN LOCALLY:
---------------------

Step A: Start the Backend Server
  1. Open a terminal and navigate to the backend folder:
     cd backend

  2. Install dependencies (if not already installed):
     npm install

  3. Start the server:
     npm start
     (or: node server.js)

  By default, the backend will start on:
  http://localhost:3000
  Health check: http://localhost:3000/api/health

Step B: Open the Frontend
  You can serve the frontend files using any static file server, for example:
  - Using Python:
      python -m http.server 5500
      Then open http://localhost:5500 in your browser.
  - Or using Node:
      npx serve .
  - Or using VS Code "Live Server" extension.
  - Or simply double-click index.html in your browser.


3. CONFIGURING THE BACKEND URL:
------------------------------
The file "config.js" has exactly one line:
  window.STOCKFLOW_API = "http://localhost:3000/api";

When deploying your backend online (e.g., Render, Railway, Fly.io),
simply replace "http://localhost:3000/api" in config.js with your live URL, e.g.:
  window.STOCKFLOW_API = "https://stockflow-api.onrender.com/api";


4. BACKEND ENVIRONMENT VARIABLES:
--------------------------------
The backend server supports the following environment variables:
- PORT              : Port number for Express server (default: 3000)
- JWT_SECRET        : Secret key used to sign HMAC-SHA256 session tokens (default: auto-generated in .jwt-secret)
- FRONTEND_ORIGIN   : Comma-separated list of allowed frontend URLs for CORS (e.g. "https://my-stockflow.vercel.app,http://localhost:5500")
- DB_PATH           : Path to the SQLite database file (default: stockflow.db in backend folder)


5. DEPLOYMENT INSTRUCTIONS:
--------------------------

A. Deploy Backend to Render (https://render.com):
  1. Push the code to a Git repository (GitHub / GitLab).
  2. Create a new "Web Service" on Render.
  3. Set Root Directory to "backend".
  4. Build Command: npm install
  5. Start Command: npm start
  6. Add Environment Variables:
     - NODE_VERSION = 22.0.0 (or LTS)
     - FRONTEND_ORIGIN = https://your-frontend-domain.vercel.app
     - JWT_SECRET = [Generate a secure 64-character random string]
     - DB_PATH = /var/data/stockflow.db (attach a persistent disk if needed)

B. Deploy Frontend to Vercel or Netlify:
  1. The frontend consists of pure HTML, CSS, and JS (no build step needed).
  2. In config.js, set your Render backend API URL.
  3. Deploy the root directory as a static site on Vercel or Netlify.


6. QUICK START & TESTING WORKFLOW:
---------------------------------
1. Open index.html in your browser.
2. Select your preferred language (English, Kannada, or Hindi) from the top-right switcher.
3. Click "New user? Register here" and complete the 3-step registration:
   - Step 1: Shop Name, Owner Name, Shop Type
   - Step 2: Owner's Mobile, Address, Pincode
   - Step 3: Email, Username, Password
4. Log in with your new credentials.
5. On the Inventory page:
   - Click "Import CSV" and select "sample_inventory.csv".
   - 40 general store items with categories, prices, quantities, and expiry dates will load immediately.
6. On the Billing page:
   - Click products to add to cart.
   - Test quantity limits (cannot exceed available stock).
   - Enter a customer name (new names prompt to save customer).
   - Choose Full Payment or Partial (Udhaar).
   - Click "Complete & Print" to generate the bill, decrease inventory stock, and open the printable receipt.
7. On the Customers page:
   - Check outstanding Udhaar.
   - Click "Receive Payment" to collect money (oldest pending invoices clear first).
8. On the Sales History page:
   - View past bills, print receipt, or click "Cancel Bill" to return stock back to inventory.
   - Click "Daily Closing Report" for end-of-day reconciliation.
9. Staff Management:
   - Create staff accounts. Staff can only open the billing screen, enforced by both screen and server.
